# M152 ExternalString 연구 — 공개 결과 근거 요약

2026-10-02 편집 기준. 대상은 Chrome 152.0.7977.64, 이슈 532204454다. 이 문서는 공개 가능한 로컬 결과와 수치의 해석 범위를 정리한다.

## 자료와 대조 범위

제공된 연구 묶음에는 연구보고서, 일부 체크포인트, 진행 기록과 집계 자료가 포함된다. 해시 목록의 파일 무결성은 확인했지만, 이번 편집에서 원본 PoC를 다시 실행하지는 않았다. 파일 무결성과 실험 재현은 서로 다른 확인이다.

## 연구 기간과 초기 관측

집중 기록 기간은 2026-09-07부터 09-16까지다. 공유 호스트 약 950회에서는 UAF 판정이 관측되지 않았고, 분리한 d8 조건에서는 150회 중 11회가 기록됐다. `11/150`은 약 7.33%이며 다른 환경의 표본과 합치거나 브라우저 전체 완료율로 바꾸지 않았다.

## 성공률 안정화 과정

연구는 환경 분리, 의미 있는 winner 판정, race window 안의 비동기 작업·로깅 제거, dangling holder와 allocator 상태를 만드는 객체의 수명 분리, 정확한 주소 재사용 측정, 연속해서 필요한 레이스 수 축소, 시도별 새 렌더러 사용 순으로 진행됐다.

단일 관측값 `p = 11/150`을 독립·동일확률 모형에 넣으면 `p² ≈ 1/186`, `p³ ≈ 1/2,536`, `p⁴ ≈ 1/34,578`, `p⁵ ≈ 1/471,512`, `p⁶ ≈ 1/6,429,711`이다. 이는 초기 설계의 복잡도를 비교하는 이론값이며 측정된 브라우저 완주율이 아니다.

## 조건부 판정과 전체 시행

특정 후반 단계의 적격 분기는 `5/5`, 같은 실험군에서 upstream race를 포함한 전체 완료 출력은 `2/60`이었다. 조건부 `5/5`를 전체 성공률 100%로 사용할 수 없다. 후반 반복 검증에는 실행 묶음 단위에서 실패가 관측되지 않았다고 기록되어 있지만, 정확한 최종 분모가 보존되지 않아 확정 `N/N`이나 통계적 신뢰구간은 제시하지 않는다.

## 로컬 결과와 권한

보고서는 디버거나 상위 프로세스의 메모리 관측에 의존하지 않은 로컬 `/etc/hosts` 읽기 사례를 기록한다. 로컬의 비활성 프로세스 sandbox와 사전 부여 권한은 실행 전제다. 결과는 기존 권한에서의 체인 완료를 보여 주며 새 OS 권한 획득을 의미하지 않는다.

## 공개 범위

공개 글은 빌드 전용 주소, 전체 PoC와 제어 흐름 세부를 제외한다. 원인 코드, `h1/h2` 상태 변화, 객체 크기 클래스, 측정값과 패치 불변식은 재검토 가능한 범위로 남긴다.

동봉된 `evidence-summary.SHA256SUMS`는 한국어·영문 요약 파일 자체의 해시다. 원본 실험 결과가 재현됐다는 인증을 의미하지 않는다.
